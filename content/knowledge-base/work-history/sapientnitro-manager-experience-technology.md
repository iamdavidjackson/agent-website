# Responsibilities

- Led development of modern enterprise-level web applications for major clients in Retail, Automotive, and Finance sectors.
- Built scalable frontend solutions using ReactJS and NodeJS integrated with Adobe Experience Manager (AEM).
- Combined hands-on technical leadership with strategic architectural thinking.
- Mentored teams and fostered collaboration across time zones and disciplines.
- Managed globally distributed teams across multiple geographies.

# Projects

- Saks Fifth Avenue: Architected and built a NodeJS-based orchestration layer unifying data from CRM, eCommerce platform, and AEM CMS. The React frontend delivered a rich, dynamic user experience. Later redesigned and rebuilt the platform, which became a core Sapient portfolio offering for connected systems across other clients.
- Fiat Chrysler Automobiles (now Stellantis): Led a globally distributed team across five geographies to simultaneously launch websites for Jeep, Chrysler, Ram Trucks, Dodge, and Alfa Romeo. Each site was powered by a shared component library and early-stage design system tailored to unique brand themes, including the mission-critical Build & Price configurator.

# Successes

- The Saks Fifth Avenue NodeJS orchestration platform was adopted as a core Sapient offering, enabling connected systems for multiple subsequent clients.
- Successfully launched five Fiat Chrysler Automobiles brand websites simultaneously with a globally distributed team.
- Established shared component library and early design system across five automotive brands.

# Lessons Learned

- A shared orchestration layer and component library multiplies team velocity across parallel client engagements.
- Leading distributed global teams requires intentional communication structures and clearly defined ownership.
