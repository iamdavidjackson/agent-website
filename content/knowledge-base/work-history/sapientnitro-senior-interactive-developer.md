# Responsibilities

- Delivered innovative digital experiences through modern frontend development and CMS integration.
- Built high-performance components and developed custom integrations for enterprise CMS platforms.
- Contributed to industry-first digital products in the automotive and retail sectors.

# Projects

- Harley-Davidson: Led frontend development for the global multi-lingual website integrated with Adobe Experience Manager (AEM) using jQuery and RequireJS. Developed a custom module loader for the AEM authoring environment. Built several award-winning microsites featuring custom CSS animations, parallax transforms, and streaming video — among the first fully responsive mobile-friendly campaigns of their kind. Extended ExpressionEngine CMS with a custom plugin that automated translation imports from Excel, significantly accelerating localization and content deployment.
- Loblaw Digital: Helped launch North America's first Click & Collect online grocery store built with jQuery and BackboneJS, powered by the SAP Hybris ecommerce engine. Implemented a custom event emitter pattern to synchronize cart and pricing updates across the site in real time.

# Awards

- Award-winning Harley-Davidson microsites recognized for innovative use of responsive design, CSS animation, and streaming video.

# Successes

- Delivered North America's first Click & Collect online grocery store for Loblaw Digital, setting the foundation for modern grocery eCommerce platforms.
- Automated Harley-Davidson's translation workflow with a custom ExpressionEngine plugin, significantly reducing localization time.
- Built custom AEM module loader to meet complex authoring requirements at Harley-Davidson.

# Lessons Learned

- Custom event emitter patterns can elegantly solve real-time state synchronization problems without a heavy framework.
- CMS authoring experience is often as important as the customer-facing result — investing in authoring tooling pays dividends.
