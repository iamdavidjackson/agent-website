# Description

An in-progress BSc Computer Science with a specialization in Machine Learning and Artificial Intelligence. Machine learning provides a means for computer systems to extract useful information from data — techniques widely used across technology, finance, medicine, education, video games, engineering, and creative fields like music. The program prepares graduates for technical, problem-solving roles in a rapidly growing area, with a typical target title of machine learning engineer. It bridges theoretical computer science with applied AI engineering, covering areas such as recommender systems, computer vision, predictive modelling, and emerging AI application domains.
