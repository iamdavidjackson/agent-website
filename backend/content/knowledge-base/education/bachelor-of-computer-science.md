# Description

A broad computer science program that combined theory, software engineering, and human-centered design. It built a foundation for understanding both the mechanics of software systems and the importance of making them usable and meaningful.

# Comments

This program was especially valuable because it connected technical problem-solving with communication, systems thinking, and interface design rather than treating those as unrelated skills.
